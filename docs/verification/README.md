# Public verification reports

These reports record checks performed against the source version and environment
described in each report. Historical results are not current compatibility claims.

Deployment identifiers in the public copies are redacted. Reserved example
domains, generic host labels and paths such as `/srv/example-matrix` are
placeholders, not live endpoints or instructions to access a particular server.
The verification outcomes, timestamps and source revisions are retained.

Keep actual service domains, mailbox addresses, sender rules, host aliases,
deployment locations, credentials and raw evidence in private operator storage.
Repository examples must use reserved example domains and operator-supplied
configuration. Do not copy live `.env` files or deployment configuration into a
report, issue, pull request or release archive.

Redacting the current files does not erase earlier Git commits or previously
published copies.
