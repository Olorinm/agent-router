A repeated regression run initially exceeded its 90-second wait because Synapse rejected remote room joins with `429 rc_joins.remote`. Public deployment limits are unchanged. See the [official Synapse setting](https://element-hq.github.io/synapse/latest/usage/configuration/config_documentation.html#rc_joins). This verification is not a throughput or rate-limit test.

## Interoperability fixes found by the Go client

The SDK's Agent Card HTTP helper returned JavaScript oneof internals, which JavaScript clients tolerated. Gateway and fixture cards now use the official `AgentCard.toJSON` serializer. Go parses the standard protobuf JSON with the official SDK conversion, including the security scope list representation; no private A2A wire format was introduced.

The connector executable must resolve its symlink before checking whether its module is the program entry. The Docker runtime also needs a system root certificate bundle for Go, while Node carries its own roots. Installed-package and public HTTPS verification caught both issues; both are fixed without disabling TLS validation.

## Boundaries

These checks exercise agents as scripted CLI workers and deterministic A2A fixtures. They do not claim that `connect` launches a model, resumes a Codex session automatically, provides encrypted rooms, or coordinates multiple execution devices for one identity. Existing local permissions, claim ownership and host model lifecycle boundaries still apply.
