# Matrix 客户端完整接入验收

本次按用户流程整体接入 Matrix 原生客户端能力。Synapse 是通信与账号数据的权威来源；SQLite 保存可重建的通信缓存，以及不可随意重建的 Agent 执行记录。界面形态不作为验收目标。

用户随后明确不要求兼容旧版本，授权删除旧代码和兼容数据。本轮移除旧协议及 Go CLI，不实施旧联系人、身份或任务迁移。

原生客户端验收证据见 [0.4 报告](matrix-native-client-2026-09-07.md)。该版本仍要求接收方绑定 A2A 服务，尚未覆盖双方只用 CLI 执行的流程。0.5 补齐了这部分，证据见 [CLI 执行报告](matrix-cli-work-2026-09-07.md)。

## CLI 执行闭环

- [x] 双方仅登录并运行连接器，不需要实现或绑定 A2A 服务。
- [x] 发送立即返回可查询的回执；接收方审批后领取输入、回传进度和结果。
- [x] 稳定 worker 独占领取，重复领取和重复回复幂等，重启后恢复原领取。
- [x] 同一会话双方可主动发起，补充输入继续原请求，旧领取凭据不能覆盖新输入。
- [x] 未领取工作直接取消；执行中取消必须先停止并由 Agent 确认。
- [x] 离线补收、失败返回、许可撤销/屏蔽、过大结果回滚与执行端切换保护。
- [x] 两个真实 Synapse 的 CLI 专项验收，以及原有 A2A/Matrix 客户端回归。

## 已完成的流程

- [x] 原生注册/登录后能直接操作账号、查询用户、创建会话。
- [x] 联系人和备注保存到私有 Matrix account data，在另一设备恢复。
- [x] 私聊关联使用 m.direct，双方加入后均可在同一个房间主动发消息或新任务。
- [x] 屏蔽/解除屏蔽使用 m.ignored_user_list，并在执行层再次检查；删除联系人不删除聊天历史。
- [x] 目录搜索使用 homeserver 的 user_directory/search，查询资料使用原生 profile；不构造全联邦名单。
- [x] 普通 Matrix 文本可收发、查历史、标记已读、观察新事件；普通消息不会隐式执行 Agent。
- [x] 陌生邀请可查看、接受、拒绝；入房后消息可见，执行请求单独审批。
- [x] 账户数据和房间历史在新设备可恢复，历史执行请求不会因新建缓存而重放。
- [x] 无公网端口的 A2A 接入、原生账号接入和已有任务/会话持久化验收继续通过。
- [x] CLI 提供完整帮助与 Agent 可直接使用的接入说明；明确执行端的启动/续接职责。
- [x] 两个真实 Synapse 验证标准 API 互操作、跨设备同步和双向原会话交流，更新柔佛部署。

## 明确的边界

执行许可、任务与运行时映射仍由 Agent 适配层维护。Matrix 通信数据跨设备恢复不等于迁移模型内部会话或允许多设备同时执行。现有单执行器约束、未知接受结果不重试策略继续有效。目录可见范围遵循 Matrix/homeserver 规则，不把自定义 private/unlisted/directory 标签冒充 Matrix 的身份隐身功能。

本轮不新增图形界面，不修改已恢复的原服务器，不把同机双 homeserver 验收表述为两个独立公网物理节点。E2EE/密钥恢复、SSO/OAuth 和模型运行时的通用迁移不包含在这份客户端接入验收中，现有不支持的入口必须明确报错。
